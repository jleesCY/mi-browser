# mi. Browser 🌐

**mi.** (pronounced "my") is a hyper-lightweight, distraction-free mobile browser designed for the modern web. 

## 🌐 Visit the Website
For a full visual overview, features, and installation guide, visit our official site:
**[jleescy.github.io/mi-browser](https://jleescy.github.io/mi-browser)**

---

## 🚀 Quick Overview
**mi.** rethinks the mobile browsing experience by replacing the traditional toolbar with a single, intelligent "Pill" interface. 

- **The Pill:** A single gesture-driven control center.
- **Deep Customization:** Adaptive theming and visual shaping.
- **Privacy First:** HTTPS only, cookie blocking, and local history.

## 📥 Installation
We provide a direct APK download for Android users on the [Releases Page](https://github.com/jleescy/mi-browser/releases).
